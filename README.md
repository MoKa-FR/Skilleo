# Skilleo

Plateforme web de formation pratique à l'intelligence artificielle.

La documentation normative du produit vit dans [`docs/`](./docs/README.md) — à lire avant toute contribution, humaine ou IA.

## Développement

```bash
pnpm install
pnpm dev
```

Ouvrir [http://localhost:3000](http://localhost:3000).

Stack : Next.js (App Router) + TypeScript + Tailwind CSS — voir `docs/DECISIONS.md` (D-04).
